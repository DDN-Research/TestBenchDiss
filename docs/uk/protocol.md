# Протокол обміну ПК ↔ стенд

Фізичний канал: USB, віртуальний COM-порт (USB CDC мікроконтролера STM32H723).
Швидкість порту для USB CDC не має значення (використовуйте 115200). Одне
повідомлення – один рядок ASCII, що закінчується `\n` (`\r` ігнорується).
Команди нечутливі до регістру.

## Команди (ПК → стенд)

| Команда | Опис | Відповідь |
|---|---|---|
| `PING` | перевірка зв’язку | `#OK PONG` |
| `INFO` | назва і версія прошивки, UID, джерело параметрів | `#INFO fw=…;ver=…;uid=…;params=eeprom\|defaults` |
| `HELP` | короткий перелік команд | кілька рядків `#OK` |
| `STREAM <мс>` | період телеметрії: 0 – вимкнено, 100…10000 | `#OK STREAM 1000` |
| `MODE AUTO` / `MODE MANUAL` | режим роботи | `#OK MODE …` + `#EVT MODE …` |
| `STOP` | безпечний стан: усі виходи вимкнено, режим РУЧНИЙ | `#OK STOP` |
| `OUT K<n> 0\|1` | реле K1..K5 (лише РУЧНИЙ, блокування діють) | `#OK OUT K2 1` або `#ERR 3 interlock: no water` |
| `PWM <n> <0..100>` | ШІМ-вихід PW1..PW4, % (РУЧНИЙ) | `#OK PWM 1 40` |
| `RGB <RRGGBB>` | колір стрічки WS2812 (РУЧНИЙ) | `#OK RGB FF60A0` |
| `BUZ <мс>` | зумер, до 5000 мс | `#OK BUZ 200` |
| `PARS` | усі параметри | рядки `#PAR …` + `#OK PARS 36` |
| `GET <ім’я>` / `SET <ім’я> <значення>` | читання / зміна параметра (в ОЗП) | `#PAR …` або `#ERR 2 value out of range` |
| `SAVE` / `DEFAULTS` | запис параметрів в EEPROM / типові значення | `#OK SAVE` |
| `TIME [РРРР-ММ-ДД гг:хх:сс]` | читання / встановлення годинника | `#OK TIME …` |
| `CAL W1\|W2 DRY\|WET` | запам’ятати поточну напругу датчика як точку калібрування | `#OK CAL W1 DRY 2790 mV` |
| `FAULT <ім’я> 0\|1` | імітація несправності: T1 T2 T3 RH W1 W2 TANK F030 RS485 | `#OK FAULT TANK 1` |
| `FAULTS` | перелік імітованих несправностей | `#OK FAULTS T1=0 …` |
| `MON 485\|SPI 0\|1` | монітор шини RS-485 / M8SPI | рядки `#BUS …` |
| `NODES` | стан вузлів RS-485 | `#NODE 1 ok=1;type=30;id=C021;err=0;v=724/1` |
| `ERRCLR` | скинути слово помилок (перераховується щосекунди) | `#OK ERRCLR` |

Коди помилок: `1` невідома команда, `2` неправильний аргумент або діапазон,
`3` не дозволено (режим або блокування), `4` невідоме ім’я, `5` апаратна помилка (EEPROM/RTC).

## Повідомлення (стенд → ПК)

`#TEL` – телеметрія, пари `ключ=значення` через `;`, `-` – немає достовірного значення:

```
#TEL ms=14738;time=2026-11-27 10:15:08;mode=AUTO;T1=29.30;T2=22.80;T3=20.80;T4=-;…;
TA=29.7;RH=48.6;W1=59.3;W2=56.3;LIGHT=49.3;UV=444;CO2=788;LVL=1;FULL=0;
A1=1911;…;A12=49;K=10000;P1=41;P2=0;P3=0;P4=0;RGB=000000;WAT=2;UVD=4.1;F030=1;ERR=02000000
```

| Ключ | Значення |
|---|---|
| T1…T8 | температури DS18B20, °C (T1 повітря, T2 ґрунт, T3 вода) |
| TA, RH | температура AM2301A, °C; відносна вологість, % |
| W1, W2 | вологість ґрунту після калібрування, % |
| LIGHT, UV | освітленість, %; напруга модуля УФ, мВ |
| CO2 | ppm від вузла CO₂ на шині RS-485 |
| LVL, FULL | вода вище електрода MIN; бак повний |
| A1…A12 | напруга на клемах аналогових входів, мВ |
| K | реле K1..K5 рядком, `10000` – увімкнено K1 |
| P1…P4 | шпаруватість ШІМ, % |
| WAT | стан поливу: 0 очікування, 1 насос, 2 пауза |
| UVD | накопичена за добу доза УФ |
| ERR | слово помилок, шістнадцяткове (див. нижче) |

`#EVT` – події: перемикання реле з причиною (`#EVT K1 ON T1=25.3 < 25.5`), аварії,
зміна режиму, несправності, кнопки. `#BUS 485 TX 53 14 01 00 08 00 00 01 4F` – монітор шини.

## Слово помилок

| Біт | Значення |
|---|---|
| 00000004 | датчик температури (DS) не готовий |
| 00000010 | модуль RS-485 не відповідає |
| 00004000 | відсутні деякі датчики вологості ґрунту |
| 00008000 | відсутні всі датчики вологості ґрунту |
| 00010000 | у баці немає води |
| 01000000 | немає зв’язку з STM32F030 (M8SPI) |
| 02000000 | образ EEPROM недійсний, використано типові параметри |
| 04000000 | годинник реального часу не відповідає |
| 08000000 | перегрів (> SAFE_TMAX) |
| 10000000 | відсутній датчик AM2301A |

Молодші біти відповідають таблиці помилок інструкції D2.GreenHouse; біти 24–28 – специфічні для прошивки стенда.
